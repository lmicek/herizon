# Herizon Docs

Welcome to the Herizon documentation.

## Mission

To empower girls, women, and those who identify as female in North Carolina to achieve
independence by equipping them with the AI tools, mentorship, and opportunities to build
sustainable careers.

## About these docs

This folder is built with [MkDocs](https://www.mkdocs.org/). Add new pages as Markdown
files in the `docs/` folder and list them under `nav:` in `mkdocs.yml`.
